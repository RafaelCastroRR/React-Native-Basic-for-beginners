## 📌 Descripción del Proyecto

**Mobile App Hub** es un proyecto enfocado en la construcción de interfaces móviles nativas y reactivas. Explora los patrones fundamentales del desarrollo móvil moderno: ciclo de vida de componentes nativos, navegación declarativa por pilas y pestañas, optimización de listas dinámicas con `FlatList` y almacenamiento en dispositivo mediante `AsyncStorage`.

---

## ✨ Funcionalidades Principales

- **Navegación Modular:** Sistema de navegación robusto basado en **React Navigation** con Bottom Tabs y Screen Stacks.
- **Gestión de Tareas Interactivas:** Creación, edición, marcado de completado y eliminación de tareas con feedback táctil.
- **Persistencia en Dispositivo:** Almacenamiento local para garantizar que los datos se conserven al cerrar la aplicación.
- **Diseño Adaptable:** Componentes estilizados con StyleSheet para mantener coherencia visual tanto en Android como en iOS.

---

## 🛠️ Tecnologías y Librerías

- **Framework Móvil:** React Native (CLI / Expo)
- **Tooling:** Expo SDK
- **Navegación:** `@react-navigation/native` & `@react-navigation/bottom-tabs`
- **Iconografía:** `@expo/vector-icons` (Ionicons, MaterialIcons)
- **Persistencia:** `@react-native-async-storage/async-storage`

## 🚀 Instalación y Ejecución

### Prerrequisitos
- Node.js (v18 o superior)
- Aplicación **Expo Go** instalada en tu smartphone (Android o iOS) o emulador configurado (Android Studio / Xcode).

### 1. Clonar el repositorio
```bash
git clone git@github.com:RafaelCastroRR/React-Native-Basic-for-beginners.git
cd React-Native-Basic-for-beginners
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Iniciar el servidor de desarrollo
```bash
npx expo start
```

### 4. Probar en el dispositivo
Escanea el código QR que aparecerá en tu terminal desde la cámara (iOS) o desde la aplicación **Expo Go** (Android).
